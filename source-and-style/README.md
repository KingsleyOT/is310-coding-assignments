## Assignment 1: Inspecting the Cultural Web

### Website
For this assignment, I inspected Kaggle, specifically the Student Mental Health Dataset page.

Website:
https://www.kaggle.com/datasets/aminasalamat/mental-health-of-students-dataset

### Web Technologies

I used the browser's Inspect/Developer Tools to look at how the website was built. I found that the page uses HTML to organize the content of the webpage. There is also CSS being used to control how the website looks, including things like the layout, colors, fonts, and spacing.

The website also uses JavaScript. This makes sense because Kaggle has many interactive features, such as menus, buttons, searching, and navigating between different parts of the site.

While inspecting the site, I noticed that there were many files and pieces of code that were more complicated than basic HTML and CSS. This showed me that a large website like Kaggle uses several technologies together instead of just simple HTML pages.

### Who Built the Website?

Kaggle is the organization behind the website. Kaggle is owned by Google.

It is difficult to determine exactly how many individual people worked on the website just by inspecting the source code. However, the size and complexity of the website suggest that it was created and maintained by a larger development team rather than one person.

### What I Learned

This activity helped me understand that websites that look simple on the screen can have a lot happening behind them. HTML provides the structure, CSS controls the appearance, and JavaScript adds interactive features. Inspecting the website made these technologies easier to understand because I could see how they are actually being used on a website.
