\# The Transfer Market Maze

\## Kingsley Osei-Tutu



Welcome to the Transfer Market Maze!



This maze explores how professional soccer players are represented and valued through data. Your goal is to navigate through different aspects of player performance and find the final explanation of player value.



\## How to Play



Unzip the transfer-market-maze.zip file.



Use the command line to explore the folders and read the clues. Some paths lead to dead ends, while others move you closer to the solution.



\### Useful PowerShell Commands



dir



cd folder-name



cd ..



Get-Content filename.txt



Get-ChildItem -Force



\### Windows PowerShell Users



Before starting the maze, run:



Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass



.\\hide-dotfiles.ps1



Read each clue carefully. You may eventually need to look for something that is not normally visible.



Good luck!
